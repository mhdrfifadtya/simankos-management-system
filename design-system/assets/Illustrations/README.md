`skyline.svg`: the two building silhouettes from the admin login screen (1440×160, `navy-600` #1E293B at 60% and 80%), pinned to the bottom edge with `preserveAspectRatio="none"`.

The login screen also scatters 40 lit windows (4×6px, `sky`, 30–80% opacity) at random positions on each page load; those are not part of this file. The tenant app's fuller, deterministic skyline is the SkylineBackground component.
