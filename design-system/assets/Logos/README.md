The brand mark as the admin sidebar and login screen draw it.

- `simankos-mark.svg`: 36×36 tile, `sky` → `sky-deep` gradient (135°), `radius-lg` corners, white house glyph. Place on `navy` or `surface`, with `shadow-brand` beneath on navy. Show "SiManKos" beside it in ExtraBold.
- `simankos-glyph.svg`: the bare house glyph (Heroicons "home", stroke 2.5), ink `navy` #0F172A. For monochrome use; recolour by editing the stroke.

There is no separate wordmark file in the codebase: the name is always live text.
