# Badge

A small pill that states a record's status in a table or card header.

Use `.badge` with one colour class. The colours carry fixed meanings across the panel:

| Class | Meaning | Examples |
| --- | --- | --- |
| `.badge-green` | Done, paid, available | Lunas, Tersedia, Aktif (kontrak) |
| `.badge-yellow` | Waiting on the tenant | Belum Bayar, Menunggu |
| `.badge-red` | Overdue or failed | Terlambat, Gagal |
| `.badge-blue` | Occupied, informational | Terisi |
| `.badge-sky` | Period or brand label | Bulan berjalan |
| `.badge-orange` | Needs attention, not urgent | Perbaikan |
| `.badge-navy` | Category | Room type |
| `.badge-gray` | Neutral or empty | Kosong, Nonaktif, Draft |

**The consumer provides** the label text only: one or two words, sentence case. Colour never carries the meaning alone, so the word must state it.
