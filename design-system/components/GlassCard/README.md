# GlassCard

The tenant app's container: a translucent navy panel (`surface`) with a hairline border over the skyline background.

Props: `children`, optional `style`, optional `accentColor` (replaces the border with a 0.75px line in that colour, used by RoomInfoCard).

Radius `radius-2xl`. Every tenant card (PaymentCard, NotificationCard, RoomInfoCard) is built on it. Source: `kosapp-mobile/src/components/GlassCard.tsx`.
